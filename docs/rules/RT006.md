# RT006: Prohibit disabling TLS verification

## Intent

Runtime code and scripts must keep certificate verification enabled.

## Current detection

The Biome plugins report:

- assigning `"0"` to `process.env.NODE_TLS_REJECT_UNAUTHORIZED`;
- setting an object property named `rejectUnauthorized` to `false`, including
  quoted property names;
- assigning `false` to a dot-notation or string-literal bracket-notation
  `rejectUnauthorized` property.

## Approved path

Fix the certificate chain, hostname, or trust-store configuration. Development
services should use a locally trusted certificate or an explicit local trust
store.

## Suppression

A suppression requires a concrete security review and must name the exact
plugin:

```ts
// biome-ignore lint/plugin/rt006-no-reject-unauthorized-false: Required by reviewed fixture RT006-legacy-cert.
const options = { rejectUnauthorized: false };
```

## Rollout

RT006 is blocking. Its initial audit covered every enabled repository and found
no current violations.
