# RT005: Prohibit dynamic code execution

## Intent

Runtime code must not use `eval`, `Function`, or equivalent dynamic execution
without a reviewed protocol-level need.

## Current detection

Biome's recommended `noGlobalEval` rule reports global `eval(...)` use. Biome's
`noImpliedEval` rule reports `Function`, `new Function`, and string arguments
passed to timer functions. Trellis enables `noImpliedEval` as an audit warning
while it remains in Biome's nursery group.

## Approved path

Use a parser, a declarative data format, or a constrained interpreter. If an
external protocol requires dynamic execution, document the protocol and
security boundary in a narrow Biome suppression.

## Suppression

```ts
// biome-ignore lint/nursery/noImpliedEval: Required by the reviewed sandbox protocol in ADR-012.
const evaluator = new Function(source);
```

## Rollout

`noGlobalEval` is already recommended and blocking. Trellis keeps
`noImpliedEval` at warning severity until all enabled repositories have been
scanned and every current finding has been triaged.
