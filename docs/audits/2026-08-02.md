# RT006 widened-detection audit

Date: 2026-08-02

Tool versions:

- Trellis `0.3.0` (unreleased source)
- Biome `2.5.6`

## Scope

Trellis 0.3.0 widens RT006's blocking detection of insecure
`NODE_TLS_REJECT_UNAUTHORIZED` assignments to include string-literal bracket
notation and numeric `0` values. Expanding a blocking rule's scope is a
breaking policy change, so the read-only audit was re-run before release.

Targets and method match the 2026-07-30 audit. For each repository, the audit
passed Git-tracked paths ending in `.js`, `.jsx`, `.mjs`, `.cjs`, `.ts`,
`.tsx`, `.mts`, or `.cts` directly to Biome with a narrow configuration
enabling only Biome's RT005 rules and the widened Trellis RT006 plugins from
source. Only `noGlobalEval`, `noImpliedEval`, and plugin diagnostics were
selected. No consumer repository was modified.

`/Users/mb1/Code/raintree/estate` is now a symbolic link to
`apps/betteroff.estate`; the Estate row below reflects that tree.

The scan processed 3,240 files and found no RT005 or RT006 diagnostics under
the widened detection. Narrow-config unused-suppression warnings (37 across
Websites, Betteroff, and Flight Sweeper) were not policy findings.

An independent Git search for `NODE_TLS_REJECT_UNAUTHORIZED` and
`rejectUnauthorized` matched only Betteroff: defensive checks that reject a
`"0"` environment value and explicit `rejectUnauthorized: true` settings.
Comparisons do not match the assignment-only plugin patterns, so the widened
forms introduce no false positives in any enrolled repository.
