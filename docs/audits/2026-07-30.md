# Initial RT005 and RT006 audit

Date: 2026-07-30

Tool versions:

- Trellis `0.1.0`
- Biome `2.5.6`

## Scope

The audit covered Git-tracked JavaScript and TypeScript files in:

- Websites, including `raintree.technology` and `zacharyr0th.com`
- Betteroff
- Flight Sweeper
- Docpull
- PolicyStrata
- HIG Doctor
- Estate

The scan ran Biome's RT005 rules and the Trellis RT006 plugins without
installing Trellis into or changing any consumer repository.

The expanded RT006 file scope was re-audited on 2026-07-31 after adding
`.mjs`, `.cjs`, `.mts`, and `.cts`. The table below reflects that wider scan.

For each repository, the audit passed Git-tracked JavaScript and TypeScript
paths ending in `.js`, `.jsx`, `.mjs`, `.cjs`, `.ts`, `.tsx`, `.mts`, or
`.cts` to Biome and selected only `noGlobalEval`, `noImpliedEval`, and plugin
diagnostics. This excluded untracked build output without depending on
machine-local cache state.

The expanded audit processed 3,140 files and found no RT005 or RT006
diagnostics. Narrow-config unused-suppression warnings were not policy
findings.

An independent Git search found Betteroff code that compares
`NODE_TLS_REJECT_UNAUTHORIZED` with `"0"` and rejects that configuration. Those
defensive checks are valid and are not reported by RT006.

## Scope finding

A first pass using a standalone shared configuration traversed generated
`.next` output, Turbo caches, and Estate's cached worktrees. Those diagnostics
were not product-source findings and were discarded.

This confirms that each consumer must keep its own root file inclusions and
generated-path exclusions. Trellis supplies shared rules; it must not guess a
repository's source boundary.
